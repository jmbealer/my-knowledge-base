- ## 4.0 Network Security 14%

  - **Goal of Domain 4**:
    - This domain focuses on identifying, preventing, and responding to security threats across networks.
    - It covers foundational concepts, real-world threats, and best practices to harden devices and control access.

  - **Things You Must Memorize**:
    - CIA Triad: Confidentiality, Integrity, Availability.
    - AAA: Authentication, Authorization, Accounting.
    - RADIUS (UDP, combines A&A) vs. TACACS+ (TCP, separates AAA).
    - Social Engineering: Phishing, Vishing, Smishing, Whaling, Tailgating.
    - Attacks: DoS/DDoS, MitM (On-path), ARP Poisoning, DNS Poisoning.
    - NAC: 802.1X, Port Security (MAC limiting/sticky).

- ### 4.1 Explain the importance of basic network security concepts

  - **CIA Triad**:
    - **Confidentiality**: Ensuring only authorized users access data (Encryption, ACLs).
    - **Integrity**: Ensuring data is not altered (Hashing, Digital Signatures).
    - **Availability**: Ensuring systems are accessible when needed (Redundancy, DoS protection).
  - **AAA Framework**:
    - **Authentication**: Proving who you are (MFA, Passwords).
    - **Authorization**: What you are allowed to do (RBAC, Least Privilege).
    - **Accounting**: Tracking what you did (Logs, Audits).
  - **Identity Management**:
    - **MFA (Multi-Factor Authentication)**: Something you know, have, are, somewhere you are, something you do.
    - **SSO (Single Sign-On)**: One set of credentials for multiple systems (SAML, OAuth).
    - **RADIUS**: Centralized AAA; often used for Wi-Fi and VPN; UDP ports 1812/1813.
    - **TACACS+**: Cisco-proprietary; separates AAA functions; encrypts the entire packet; TCP port 49.
  - **Zero Trust Architecture**: "Never trust, always verify." Every request is authenticated and authorized regardless of location.
  - **Encryption Concepts**:
    - **Data-at-rest**: Stored on disks/tapes (AES).
    - **Data-in-transit**: Moving over the network (TLS, IPsec).
    - **Data-in-use**: Being processed in RAM/CPU.
  - **Physical Security**: Surveillance (CCTV), Entrance Control (Mantraps, Badges), Environmental sensors.

- ### 4.2 Summarize various types of attacks and their impact to the network

  - **Social Engineering**:
    - **Phishing**: General deceptive emails.
    - **Spear Phishing**: Targeted at a specific individual.
    - **Whaling**: Targeted at high-level executives (CEO/CFO).
    - **Vishing**: Voice phishing (phone).
    - **Smishing**: SMS phishing (text).
    - **Tailgating**: Following someone into a secure area.
  - **Network Attacks**:
    - **DoS/DDoS**: Overwhelming a service to make it unavailable.
    - **MitM (Man-in-the-Middle) / On-path**: Intercepting communication between two parties.
    - **ARP Poisoning/Spoofing**: Associating the attacker's MAC with a legitimate IP.
    - **DNS Poisoning**: Redirecting users to a fake site by corrupting DNS cache.
    - **VLAN Hopping**: Attacker moves from one VLAN to another (Switch Spoofing or Double Tagging).
    - **MAC Flooding**: Filling the MAC table to force the switch to act like a hub (fail-open).
  - **Wireless Attacks**:
    - **Evil Twin**: A rogue AP using the same SSID as a legitimate one.
    - **Rogue AP**: Any unauthorized AP connected to the network.
    - **War Driving**: Searching for Wi-Fi networks from a moving vehicle.
  - **Malware**:
    - **Ransomware**: Encrypts data for payment.
    - **Trojan**: Malicious code hidden inside a useful program.
    - **Worm**: Self-replicating malware that spreads across networks.
    - **Rootkit**: Hides itself deep in the OS to maintain administrative access.

- ### 4.3 Given a scenario, apply network security features, defense techniques, and solutions

  - **Device Hardening**:
    - Disable unused ports and services.
    - Change all default passwords.
    - Keep firmware/OS patched.
    - Use secure protocols (SSH instead of Telnet, HTTPS instead of HTTP).
  - **Network Access Control (NAC)**:
    - **802.1X**: Port-based authentication using a RADIUS server.
    - **Port Security**:
      - **MAC Limiting**: Max number of MACs per port.
      - **Sticky MAC**: Learning and saving the MAC address to the config.
      - **Violation Actions**: Shutdown, Restrict, Protect.
  - **Segmentation & Isolation**:
    - **VLANs**: Logical separation at Layer 2.
    - **ACLs (Access Control Lists)**: Filtering traffic at Layer 3/4 based on IP, Port, or Protocol.
    - **DMZ (Screened Subnet)**: A buffer zone for public-facing servers (Web, Mail).
  - **Firewall Technologies**:
    - **Stateless**: Filters packets individually based on headers (ACLs).
    - **Stateful**: Tracks the state of active connections; only allows returning traffic if requested.
    - **NGFW (Next-Gen)**: Includes Application Layer filtering and Deep Packet Inspection (DPI).
    - **UTM (Unified Threat Management)**: All-in-one (Firewall, IPS, Antivirus, Content filtering).
  - **Detection & Deception**:
    - **IDS (Detection)**: Alerts on suspicious activity.
    - **IPS (Prevention)**: Actively blocks suspicious activity.
    - **Honeypot/Honeynet**: Decoy systems/networks used to lure and study attackers.
