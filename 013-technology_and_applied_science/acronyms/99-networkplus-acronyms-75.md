# CompTIA Network+ (N10-009) Acronym Reference

This reference categorizes essential acronyms for the Network+ exam.

## Protocols & Services
- **AAA:** Authentication, Authorization, and Accounting
- **ACL:** Access Control List
- **ARP:** Address Resolution Protocol (IP to MAC)
- **BGP:** Border Gateway Protocol (Internet-scale routing)
- **DHCP:** Dynamic Host Configuration Protocol
- **DNS:** Domain Name System
- **DNSSEC:** Domain Name System Security Extensions
- **EIGRP:** Enhanced Interior Gateway Routing Protocol (Cisco)
- **FTP/SFTP/TFTP:** File Transfer Protocols
- **HTTP/HTTPS:** Hypertext Transfer Protocol (Secure)
- **ICMP:** Internet Control Message Protocol (Ping/Traceroute)
- **IP:** Internet Protocol (v4 and v6)
- **LDAP/LDAPS:** Lightweight Directory Access Protocol (Secure)
- **NTP/PTP:** Network/Precision Time Protocol
- **OSPF:** Open Shortest Path First (Link-state routing)
- **RADIUS:** Remote Authentication Dial-In User Service
- **SIP:** Session Initiation Protocol (VoIP)
- **SMB:** Server Message Block (Windows file sharing)
- **SNMP:** Simple Network Management Protocol
- **SSH:** Secure Shell
- **TACACS+:** Terminal Access Controller Access-Control System Plus
- **TCP/UDP:** Transmission Control / User Datagram Protocols
- **TLS/SSL:** Transport Layer Security / Secure Sockets Layer

## Media & Hardware
- **APC/UPC:** Angled/Ultra Physical Contact (Fiber polish)
- **BNC:** Bayonet Neill-Concelman (Coax connector)
- **DAC:** Direct Attach Copper
- **IDF/MDF:** Intermediate/Main Distribution Frame
- **LC/SC/ST/MPO:** Fiber Optic Connectors
- **MMF/SMF:** Multimode / Single-mode Fiber
- **NIC:** Network Interface Card
- **SFP/QSFP:** Small Form-factor Pluggable (Transceivers)
- **STP/UTP:** Shielded / Unshielded Twisted Pair

## Wireless (802.11)
- **BSSID:** Basic Service Set Identifier (MAC of the AP)
- **ESSID:** Extended Service Set Identifier (Network Name)
- **MIMO / MU-MIMO:** Multiple-Input Multiple-Output
- **OFDMA:** Orthogonal Frequency-Division Multiple Access (Wi-Fi 6)
- **PSK:** Pre-Shared Key
- **SAE:** Simultaneous Authentication of Equals (WPA3)
- **SSID:** Service Set Identifier
- **WPA/WPA2/WPA3:** Wi-Fi Protected Access

## Cloud & Modern Networking
- **IaaS/PaaS/SaaS:** Infrastructure/Platform/Software as a Service
- **IaC:** Infrastructure as Code
- **NFV:** Network Functions Virtualization
- **SASE/SSE:** Secure Access Service Edge / Security Service Edge
- **SDN / SD-WAN:** Software-Defined Networking / SD-Wide Area Network
- **VPC:** Virtual Private Cloud
- **VXLAN:** Virtual Extensible LAN
- **ZTA:** Zero Trust Architecture

## Troubleshooting & Operations
- **AUP:** Acceptable Use Policy
- **BIA:** Business Impact Analysis
- **DRP:** Disaster Recovery Plan
- **EOL / EOS:** End of Life / End of Support
- **MTBF:** Mean Time Between Failures
- **MTTR:** Mean Time to Repair
- **RPO:** Recovery Point Objective (Data loss)
- **RTO:** Recovery Time Objective (Downtime)
- **SLA:** Service Level Agreement
- **SOP:** Standard Operating Procedure
