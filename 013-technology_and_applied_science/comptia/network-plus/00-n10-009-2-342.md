## 2.1 Explain characteristics of routing technologies

**Static Routing**: *Manually configured* routing entries by an administrator.

- Static routing: Manually configured routing entries by an administrator.

- **Use Cases**: Small networks, stub networks, stable environments.
- **Benefits**: Simplicity, *low overhead*, predictability, security.
- **Drawbacks**: *No auto-failover*, poor scalability, high maintenance.
**Dynamic Routing**: Routers *automatically exchanging* path information.
  - Dynamic routing: Routers automatically exchanging path information.
- **Use Cases**: Large networks, *changing topologies*, internet.
- **Benefits**: Scalability, adaptability, *automatic failover*.
- **Drawbacks**: Complexity, *resource usage*, security risks.
- **Routing Protocols**:
  - **RIP (Routing Information Protocol)**: *Distance-vector* using hop count (max 15).
    - RIP (Routing Information Protocol): Distance-vector routing protocol using hop count.
  - **OSPF (Open Shortest Path First)**: *Link-state* using Dijkstra algorithm; organized into **Areas**.
    - OSPF: Link-state routing protocol using Dijkstra's algorithm.
      - OSPF (Open Shortest Path First): Link-state routing protocol using Dijkstra's algorithm.
  - **EIGRP (Enhanced Interior Gateway Routing Protocol)**: *Advanced distance-vector* using bandwidth and delay; fast convergence.
    - EIGRP: Cisco routing protocol using bandwidth and delay.
      - EIGRP (Enhanced Interior Gateway Routing Protocol): Cisco routing protocol using bandwidth and delay.
  - **BGP (Border Gateway Protocol)**: *Path-vector* protocol routing between **Autonomous Systems (AS)** on the internet.
    - BGP: Protocol routing between internet autonomous systems.
      - BGP (Border Gateway Protocol): Protocol routing between internet autonomous systems.

**Route Selection Concepts**:
    - **Administrative Distance (AD)**: *Trustworthiness* of a route source (lower is better; e.g., Directly Connected = 0, Static = 1, OSPF = 110).
      - Administrative distance: Metric rating the trustworthiness of routing sources.
    - **Metric**: Value used to *evaluate the cost* of a path (e.g., Hop Count for RIP, Cost for OSPF).
    - **Prefix Length**: Number of bits identifying the network; **Longest Match Rule** applies first.

**Address Translation**:
    - **NAT (Network Address Translation)**: Mapping private IP space to public IP.
      - NAT: Modifying IP addresses in packet headers.
          - NAT (Network Address Translation): Modifying IP addresses in packet headers.
    - **PAT (Port Address Translation)**: Many-to-one mapping using unique source ports (Overloading).
      - PAT: Sharing one public IP via multiple ports.
          - PAT (Port Address Translation): Sharing one public IP via multiple ports.

**First Hop Redundancy Protocol (FHRP)**: Provides gateway redundancy (e.g., HSRP, VRRP).

- FHRP: Provides failover for default gateways.
  - FHRP (First Hop Redundancy Protocol): Provides failover for default gateways.

**Virtual IP (VIP)**: Shared IP address used by the active gateway in a cluster.

- Virtual IP (VIP): Shared IP address for cluster failover.
  - VIP (Virtual IP): Shared IP address for cluster failover.

**Subinterfaces**: *Logical interfaces* (e.g., eth0.10) on a physical port to support multiple VLANs (Router-on-a-Stick).

## 2.3 Given a scenario, select and configure wireless devices and technologies

**Channels**: Specific *frequency ranges* for wireless communication.

- **Channel Width**: *Frequency span* used for data transmission (MHz).
      - Channel width: Frequency range used for data transmission.
- **Non-Overlapping Channels**: *Adjacent channels* that do not interfere (1,6,11).
- **Regulatory Impacts**: *Legal restrictions* on wireless frequency and power.
  - **802.11h**: Standard for *dynamic frequency selection* and power.
          - 802.11h: Wi-Fi amendment preventing interference with radar.
    - **Dynamic Frequency Selection (DFS)**: Automatically *switching channels* to avoid radar interference.

**Frequency Options**: *Radio bands* available for wireless data transmission.

- **2.4GHz**: *Low-frequency* band with high penetration and range.
- **5GHz**: *High-frequency* band with high speed and capacity.
- **6GHz**: *Ultra-high* frequency band for Wi-Fi 6E devices.
- **Band Steering**: *Directing dual-band clients* to optimal frequency bands.

**Service Set Identifier (SSID)**: *Name identifying* a wireless network.

- SSID: Name identifying a wireless network.
  - SSID (Service Set Identifier): Name identifying a wireless network.

- **Basic Service Set Identifier (BSSID)**: Unique *MAC address identifying* a specific radio.
      - BSSID: MAC address of a wireless access point.
          - BSSID (Basic Service Set Identifier): MAC address of a wireless access point.
- **Extended Service Set Identifier (ESSID)**: Shared *network name across* multiple access points.
      - ESSID: Network name across multiple access points.
          - ESSID (Extended Service Set Identifier): Network name across multiple access points.

**Network Types**: Different *configurations* for wireless network connectivity.

- **Mesh Networks**: *Decentralized nodes* providing self-healing redundant pathways.
      - Mesh networks: Wireless nodes acting as repeaters.
- **Ad Hoc**: *Peer-to-peer* connection without central infrastructure (IBSS).
- **Point-to-Point**: *Direct wireless link* between two specific locations.
- **Infrastructure**: Network *managed by* central access points (BSS).

**Encryption**: *Scrambling* wireless data to ensure privacy.

- **Wi-Fi Protected Access 2 (WPA2)**: *Security standard* using **AES-CCMP** for strong encryption.
      - WPA2: Standard Wi-Fi security using AES encryption.
- **Wi-Fi Protected Access 3 (WPA3)**: *Latest security* using **SAE** for individualized encryption.
      - WPA3: Latest Wi-Fi security with improved encryption.
- **Wi-Fi Protected Access (WPA)**: *Legacy security* replacing vulnerable WEP standard.
      - WPA (Wi-Fi Protected Access): Security standard for wireless networks.
- **Wi-Fi Protected Setup (WPS)**: Simplified but *insecure* device connection method.
      - WPS (Wi-Fi Protected Setup): Insecure simplified wireless connection method.

**Guest Networks**: *Isolated wireless segments* for temporary users.

- **Captive Portal**: *Webpage requiring interaction* before granting network access.
      - Captive portals: Webpage requiring interaction before network access.
**Authentication**: *Verifying identity* of wireless clients before access.
- **Pre-Shared Key (PSK)**: *Shared passphrase* used by all network users.
      - Pre-shared key (PSK): Password shared by all users for access.
      - PSK (Pre-shared Key): Password shared by all users for access.
- **Enterprise (802.1X)**: *Centralized authentication* using individual user credentials.

**Antennas**: Devices for *transmitting and receiving* radio waves.

- **Omnidirectional Antenna**: Radiating radio signals in *all directions equally*.
- **Directional Antenna**: Focusing radio signals in a *specific direction*.

**Autonomous vs. Lightweight Access Point**: *Standalone* management versus *controller-based* management.

- **Autonomous**: *Standalone access point* managing all local functions.
- **Lightweight Access Point**: *Controller-managed device* offloading logic to WLC.
