# 2.0 Network Implementation (20%)

## 2.1 Explain characteristics of routing technologies

### Route Selection Logic
1. **Longest Prefix Match:** The most specific route (e.g., /28 over /24) is always preferred first, **overriding AD**.
2. **Administrative Distance (AD):** Trustworthiness of the source.
3. **Metric:** The "cost" within a specific protocol.
    - **RIP:** Hop Count (max 15).
    - **OSPF:** Cost (based on Bandwidth).
    - **EIGRP:** Bandwidth + Delay.

### Routing Concepts
- **Convergence:** Time taken for all routers to agree on a topology change.
- **Route Summarization:** Combining multiple contiguous networks into one advertisement to reduce table size.

### Bandwidth Management
- **Traffic Shaping:** Delays packets to conform to a bandwidth limit (smooths bursts).
- **Policing:** Drops traffic that exceeds the limit (enforces hard limits).

### First Hop Redundancy (FHRP)
- **HSRP (Cisco):** Active / Standby.
- **VRRP (Open):** Master / Backup.
- **GLBP (Cisco):** Active / Active (Load balancing).

## 2.2 Given a scenario, configure switching technologies and features

### STP Enhancements
- **PortFast:** Allows access ports to skip Listening/Learning states and move straight to Forwarding.
- **BPDU Guard:** Shuts down a PortFast port if it receives an unexpected BPDU (prevents unauthorized switches).

### Link Aggregation
- **LACP (IEEE 802.3ad):** Open standard.
- **PAgP (Cisco):** Proprietary.
