# 2.0 Network Implementation (20%)

## 2.1 Explain characteristics of routing technologies

Routing is the process of selecting a path for traffic in a network or between or across multiple networks.

### Routing Types
- **Static Routing:** Manual entries by an administrator.
    - **Pros:** Low overhead, high security, predictable.
    - **Cons:** No automatic failover, high administrative burden.
    - **Use Case:** Small, stable networks or stub networks.
- **Dynamic Routing:** Routers exchange information automatically to learn routes.
    - **Pros:** Scalable, automatic failover (convergence), adaptable.
    - **Cons:** Higher CPU/RAM usage, more complex.
    - **Use Case:** Large networks, internet.
- **Default Route:** A "catch-all" route (0.0.0.0/0) used when no specific route matches.

### Dynamic Routing Protocols
- **Interior Gateway Protocols (IGP):** Routing within a single Autonomous System (AS).
    - **OSPF (Open Shortest Path First):** Link-state, open standard, fast convergence, uses "Areas."
    - **EIGRP (Enhanced Interior Gateway Routing Protocol):** Cisco-proprietary hybrid; uses Bandwidth and Delay as metrics.
    - **RIP (Routing Information Protocol):** Distance-vector, legacy, uses Hop Count (max 15).
- **Exterior Gateway Protocols (EGP):** Routing between different Autonomous Systems.
    - **BGP (Border Gateway Protocol):** The protocol of the internet; path-vector, uses various "attributes" to select paths.

### Route Selection Criteria
1. **Prefix Length:** The most specific route (longest prefix) is always preferred first (e.g., /28 over /24).
2. **Administrative Distance (AD):** The trustworthiness of the source. Lower is better.
    - **Connected:** 0
    - **Static:** 1
    - **EIGRP:** 90
    - **OSPF:** 110
    - **RIP:** 120
3. **Metric:** The "cost" value used by the specific protocol to rank routes from the same source.

### Address Translation & Redundancy
- **NAT (Network Address Translation):** Maps private IP space to public.
- **PAT (Port Address Translation):** Maps many private IPs to a single public IP using unique ports.
- **FHRP (First Hop Redundancy Protocol):** Provides failover for default gateways (HSRP, VRRP).
    - **Virtual IP (VIP):** The shared IP address that clients use as their gateway.
- **Subinterfaces:** Logical "child" interfaces on a physical interface (Router-on-a-stick).

## 2.2 Given a scenario, configure switching technologies and features

### VLAN Concepts
- **VLAN (Virtual LAN):** Logical segmentation at Layer 2.
- **VLAN Database:** Where the switch stores VLAN definitions.
- **SVI (Switch Virtual Interface):** A logical Layer 3 interface used for inter-VLAN routing (e.g., "interface vlan 10").
- **Trunking (802.1Q):** A single physical link that carries traffic for multiple VLANs using tags.
    - **Native VLAN:** The one VLAN on a trunk that carries untagged traffic (security best practice: change from VLAN 1).
    - **Voice VLAN:** Specifically for VoIP traffic to apply QoS easily.

### Interface & Port Features
- **Speed & Duplex:** Should match on both ends (Auto-negotiation common).
    - **Full Duplex:** Simultaneous two-way.
    - **Half Duplex:** One way at a time (CSMA/CD used).
- **Link Aggregation (LACP):** Bundling multiple physical ports into one logical channel (EtherChannel) for bandwidth and redundancy.
- **Port Tagging:** The process of adding/removing the 802.1Q header.
- **PoE (Power over Ethernet):**
    - **802.3af (PoE):** 15.4W
    - **802.3at (PoE+):** 30W
    - **802.3bt (PoE++):** Up to 60W or 100W.

### Spanning Tree Protocol (STP)
- **Goal:** Prevent Layer 2 loops (broadcast storms) by blocking redundant paths.
- **RSTP (802.1w):** Much faster convergence than original STP.
- **Root Bridge:** The "center" of the STP topology; elected based on lowest Priority/MAC.

### Frame Management
- **MTU (Maximum Transmission Unit):** Standard Ethernet is 1500 bytes.
- **Jumbo Frames:** Up to 9000 bytes; used in data centers/SANs to reduce overhead.

## 2.3 Given a scenario, select and configure wireless devices and technologies

### Wireless Settings
- **Channel Width:** 20, 40, 80, or 160 MHz. Wider = faster but more interference.
- **Channels:**
    - **2.4 GHz:** Channels 1, 6, 11 are non-overlapping.
    - **5/6 GHz:** Many more non-overlapping options.
- **Regulatory Impacts (802.11h):** Includes **DFS** (Dynamic Frequency Selection) to avoid radar interference in 5 GHz.
- **Band Steering:** Moving 5 GHz capable clients away from the congested 2.4 GHz band.

### SSIDs and IDs
- **SSID:** The human-readable network name.
- **BSSID:** The MAC address of the specific radio.
- **ESSID:** The name for a group of APs acting as one network.

### Network Types
- **Infrastructure:** Centralized (Clients connect to APs).
- **Ad Hoc:** Peer-to-peer (No AP).
- **Mesh:** APs connect to each other wirelessly to extend coverage (self-healing).

### Security & Encryption
- **WPA2:** Uses AES-CCMP.
- **WPA3:** Uses **SAE (Simultaneous Authentication of Equals)** to prevent offline brute-force attacks.
- **Authentication:**
    - **PSK:** Simple shared password.
    - **Enterprise (802.1X):** Per-user login via a **RADIUS** server.
- **Captive Portal:** A web page forced on guests before they get access.

### Hardware Factors
- **Antennas:** **Omnidirectional** (360 coverage) vs. **Directional** (Patch, Yagi - focused).
- **AP Modes:**
    - **Autonomous:** Standalone management.
    - **Lightweight:** Managed by a central **Wireless LAN Controller (WLC)** using **CAPWAP**.

## 2.4 Explain important factors of physical installations

### Installation Locations
- **MDF (Main Distribution Frame):** The primary hub where outside services enter the building.
- **IDF (Intermediate Distribution Frame):** Secondary closets on other floors/wings that connect back to the MDF.

### Rack & Power
- **Rack Units (U):** Standard measurement (1U = 1.75 inches).
- **Port-side Exhaust/Intake:** Orientation of equipment to match Hot/Cold aisle layouts.
- **UPS (Uninterruptible Power Supply):** Battery backup for short outages.
- **PDU (Power Distribution Unit):** A smart "power strip" for the rack.

### Cable Management
- **Patch Panel:** Terminates horizontal cabling; allows easy changes with patch cords.
- **Fiber Distribution Panel:** Specialized termination for fiber.
- **Labeling:** Critical for maintenance and troubleshooting.

### Environmental Factors
- **Temperature:** Typically maintained between 18°C and 27°C (64°F - 81°F).
- **Humidity:** Ideally 40-60%. Too low = static; too high = corrosion.
- **Fire Suppression:** Use "Clean Agent" gases (FM-200) instead of water to protect electronics.
- **Grounding:** Metal racks must be properly grounded to prevent electrical hazards.
