# 2.0 Network Implementation (20%)

## 2.1 Explain characteristics of routing technologies

### Routing Types
- **Static:** Manual entry.
- **Dynamic:** Automatic updates via protocols.
    - **BGP (Border Gateway Protocol):** Path-vector, internet scale.
    - **EIGRP:** Advanced distance-vector (Cisco).
    - **OSPF:** Link-state.

### Route Selection & Translation
- **Criteria:** **Administrative Distance**, **Prefix Length**, **Metric**.
- **Translation:** **NAT**, **Port Address Translation (PAT)**.
- **Redundancy:** **First Hop Redundancy Protocol (FHRP)**, **Virtual IP (VIP)**.
- **Subinterfaces:** Logical child interfaces.

---

## 2.2 Given a scenario, configure switching technologies and features

### VLAN Concepts
- **VLAN**, **VLAN Database**, **Switch Virtual Interface (SVI)**.
- **Native VLAN**, **Voice VLAN**, **802.1Q Tagging**.

### Interface Features
- **Link Aggregation**, **Speed**, **Duplex**.
- **Spanning Tree (STP):** Prevents Layer 2 loops.
- **MTU / Jumbo Frames:** Max packet size (1500 vs 9000).

---

## 2.3 Given a scenario, select and configure wireless devices and technologies

### Channels & Frequencies
- **Channel Width**, **Non-overlapping Channels**.
- **Regulatory Impacts:** **802.11h**.
- **Bands:** 2.4GHz, 5GHz, 6GHz.
- **Band Steering:** Moving clients to 5GHz.

### SSIDs & IDs
- **SSID**, **BSSID** (MAC of AP), **ESSID** (Roaming group).

### Wireless Security
- **Encryption:** **WPA2**, **WPA3**.
- **Guest Access:** **Captive Portals**.
- **Authentication:** **PSK** vs. **Enterprise (802.1X)**.

### Hardware & Architecture
- **Mesh**, **Ad Hoc**, **Point-to-Point**, **Infrastructure**.
- **Antennas:** Omnidirectional vs. Directional.
- **Management:** **Autonomous** vs. **Lightweight AP**.

## 2.4 Explain important factors of physical installations

### Installation Locations
- **IDF (Intermediate Distribution Frame)**, **MDF (Main Distribution Frame)**.

### Rack & Power
- **Rack Size (U)**, **Port-side Exhaust/Intake**.
- **Lockable** cabinets.
- **Power:** **UPS**, **PDU**, **Power Load**, **Voltage**.

### Cabling
- **Patch Panel**, **Fiber Distribution Panel**.

### Environmental Factors
- **Humidity**, **Fire Suppression**, **Temperature**.
