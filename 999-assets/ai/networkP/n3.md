- ## 3.0 Network Operations 19%

  - **Goal of Domain 3**:
    - This domain covers the management, documentation, monitoring, and resilience of networks.
    - It focuses on the daily processes that keep the network functional, secure, and recoverable.

  - **Things You Must Memorize**:
    - Monitoring Tools: SNMP (v2c/v3), Syslog, NetFlow, SIEM.
    - DR Metrics: RPO, RTO, MTTR, MTBF.
    - DNS Record Types: A, AAAA, CNAME, MX, TXT, PTR.
    - DHCP Process: DORA (Discover, Offer, Request, Acknowledge).
    - Remote Access: VPN (Full vs. Split Tunnel), OOB management.

- ### 3.1 Explain the purpose of organizational processes and procedures

  - **Documentation**: Essential for troubleshooting and continuity.
    - **Physical Diagram**: Shows cable runs, device locations, and physical connections.
    - **Logical Diagram**: Shows data flow, IP addresses, subnets, and VLANs.
    - **Rack Diagram**: Visual layout of equipment in a rack (measured in U).
    - **Cable Map**: Tracking physical cable paths and terminations (Patch Panel to Jack).
    - **Asset Inventory**: Tracking hardware, software versions, licenses, and warranties.
    - **IPAM (IP Address Management)**: Tracking IP allocation to prevent conflicts.
  - **Life-Cycle Management**:
    - **End-of-Life (EOL)**: Product is no longer sold.
    - **End-of-Support (EOS)**: Manufacturer stops providing updates/support.
    - **Decommissioning**: Safe removal and data wiping of old assets.
  - **Change Management**: Formal process to request, review, and approve network changes to minimize downtime.
  - **Configuration Management**:
    - **Baseline/Golden Configuration**: Standardized settings for all devices of a type.
    - **Configuration Backups**: Regular copies of running-configs for recovery.
  - **Standard Operating Procedures (SOPs)**: Step-by-step instructions for routine tasks.

- ### 3.2 Given a scenario, use network monitoring technologies

  - **Monitoring Methods**:
    - **SNMP (Simple Network Management Protocol)**:
      - **v2c**: Uses community strings (plain text); insecure.
      - **v3**: Adds encryption and authentication; industry standard for security.
      - **Traps**: Unsolicited alerts sent from device to the NMS (Network Management System).
      - **MIB (Management Information Base)**: The database of objects a device can report on.
    - **Syslog**: Standard for system logs; centralized using a **Syslog Collector**.
    - **Flow Data (NetFlow/IPFIX)**: Tracks "who, what, where" of traffic (metadata); does not capture actual packet content.
    - **SIEM (Security Information and Event Management)**: Correlates logs from many sources to detect security threats in real-time.
    - **Packet Capture (PCAP)**: Deep packet inspection (WireShark/tcpdump); captures full traffic content.
  - **Traffic Management**:
    - **Port Mirroring (SPAN)**: Copying traffic from one port to a monitoring port.
    - **Network Tap**: A physical device that intercepts traffic on a link for analysis.

- ### 3.3 Explain disaster recovery (DR) concepts

  - **Business Continuity Metrics**:
    - **RPO (Recovery Point Objective)**: How much *data loss* is tolerable (measured in time since last backup).
    - **RTO (Recovery Time Objective)**: How much *downtime* is tolerable (time to get back online).
    - **MTTR (Mean Time to Repair)**: Average time to fix a failure.
    - **MTBF (Mean Time Between Failures)**: Average time a system runs before failing (reliability).
  - **Backup Types**:
    - **Full**: Copies all data; slowest to back up, fastest to restore.
    - **Incremental**: Copies only data changed since the *last* backup; fastest to back up.
    - **Differential**: Copies all data changed since the last *full* backup.
  - **DR Sites**:
    - **Hot Site**: Fully equipped and synchronized; nearly instant failover.
    - **Warm Site**: Equipment is present but needs configuration/data restore (hours/days).
    - **Cold Site**: Basic infrastructure (power/cooling) only; no equipment (days/weeks).
  - **High Availability**:
    - **Active-Active**: Both systems handle traffic simultaneously (load balancing).
    - **Active-Passive**: One system is on standby and takes over if the primary fails.
    - **Redundancy**: Dual power supplies, NIC teaming, FHRP (HSRP/VRRP).

- ### 3.4 Given a scenario, implement IPv4 and IPv6 network services

  - **DHCP (Dynamic Host Configuration Protocol)**:
    - **DORA**: Discover, Offer, Request, Acknowledge.
    - **Relay/IP Helper**: Forwarding DHCP broadcasts across routers to a central server.
    - **Scope**: The range of IP addresses available to clients.
    - **Exclusions**: Specific IPs within a scope that are *not* handed out.
    - **Reservations**: Mapping a specific MAC address to a permanent IP.
  - **DNS (Domain Name System)**:
    - **Record Types**:
      - **A**: Hostname to IPv4.
      - **AAAA**: Hostname to IPv6.
      - **CNAME**: Alias (one name to another).
      - **MX**: Mail server.
      - **TXT**: Text info (SPF/DKIM for email security).
      - **PTR**: IP to Hostname (Reverse lookup).
      - **NS**: Identifies authoritative name servers.
    - **Forward vs. Reverse Lookup**: Name-to-IP vs. IP-to-Name.
    - **Recursive vs. Iterative**: How a DNS server finds an answer.
    - **DNS Security**: **DNSSEC** (authenticity), **DoH** (DNS over HTTPS), **DoT** (DNS over TLS).
  - **NTP (Network Time Protocol)**: Synchronizes clocks using a **Stratum** hierarchy (Stratum 0 is the atomic clock).

- ### 3.5 Compare and contrast network access and management methods

  - **Remote Access VPN**:
    - **Client-to-Site**: Individual users (using software like AnyConnect).
    - **Site-to-Site**: Connecting two branch offices via encrypted tunnels.
    - **Full Tunnel**: *All* traffic goes through the VPN (more secure).
    - **Split Tunnel**: Only *corporate* traffic goes through the VPN; internet traffic goes local.
    - **Clientless (SSL VPN)**: Access via a web browser without special software.
  - **Management Methods**:
    - **SSH (Secure Shell)**: Encrypted CLI access (Port 22).
    - **Console**: Physical serial connection (Out-of-band).
    - **Jump Box**: A hardened server used as a single point of entry into a secure zone.
    - **In-Band Management**: Managing devices over the same network they use for data.
    - **Out-of-Band (OOB) Management**: Using a dedicated network or console server for management, ensuring access even during a data network outage.
