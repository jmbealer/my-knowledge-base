# 3.0 Network Operations (19%)

## 3.1 Explain the purpose of organizational processes and procedures

### Documentation
- **Diagrams:** **Physical vs. Logical**, **Rack Diagrams**, **Cable Maps**, **Layer 1/2/3 Diagrams**.
- **Inventory:** Hardware, Software, **Licensing**, **Warranty Support**.
- **IPAM / SLA / Wireless Survey (Heat Map)**.

### Life-Cycle Management
- **EOL (End-of-Life)**, **EOS (End-of-Support)**.
- **Software Management:** Patches, Bug fixes, OS, Firmware.
- **Decommissioning:** Secure disposal.

### Management Processes
- **Change Management:** Request process tracking / Service request.
- **Configuration Management:** Production, Backup, and **Baseline/Golden Configuration**.

## 3.2 Given a scenario, use network monitoring technologies

### Methods
- **SNMP:** **Traps**, **MIB**, **Versions (v2c, v3)**, Community strings, Auth.

- **Baseline Metrics:** Anomaly alerting/notification.

- **API Integration**, **Port Mirroring**.

### Solutions
- **Network Discovery:** Ad hoc, Scheduled.
- **Traffic Analysis**, **Performance Monitoring**, **Availability Monitoring**, **Configuration Monitoring**.

## 3.4 Given a scenario, implement IPv4 and IPv6 network services

### Dynamic Addressing
- **DHCP:** **Reservations**, **Scope**, **Lease Time**, **Options**, **Relay/IP Helper**, **Exclusions**.
- **SLAAC (Stateless Address Autoconfiguration)**.

### Name Resolution (DNS)
- **DNSSEC**, **DoH**, **DoT**.
- **Record Types:** **Address (A)**, **AAAA**, **CNAME**, **MX**, **TXT**, **NS**, **PTR**.
- **Zone Types:** **Forward**, **Reverse**.
- **Management:** Authoritative vs. Non-authoritative, Primary vs. Secondary, **Recursive**.
- **Hosts File**.

### Time Protocols
- **NTP**, **Precision Time Protocol (PTP)**, **Network Time Security (NTS)**.
