# 1.0 Networking Concepts (23%)

## 1.1 Explain concepts related to the Open Systems Interconnection (OSI) reference model

The OSI model is a conceptual framework that standardizes the functions of a telecommunication or computing system into seven abstraction layers.

### Key Concepts
- **Protocol Data Unit (PDU):** The specific form of data at each layer (Bit, Frame, Packet, Segment, Data).
- **Encapsulation:** Adding headers (and sometimes trailers) as data moves down the stack.
- **Decapsulation:** Removing headers as data moves up the stack at the receiving end.
- **Interoperability:** The ability of different systems to communicate using standardized protocols.

### The Seven Layers
- **Layer 7 - Application:** Interface for end-user processes and network services.
    - **PDU:** Data
    - **Functions:** Resource sharing, remote file access, directory services.
    - **Protocols:** HTTP, DNS, FTP, SMTP, SSH.
- **Layer 6 - Presentation:** Translates, encrypts, and compresses data for the application layer.
    - **PDU:** Data
    - **Functions:** Data representation (ASCII/Unicode), encryption/decryption (SSL/TLS), compression.
- **Layer 5 - Session:** Manages sessions between applications.
    - **PDU:** Data
    - **Functions:** Setup, maintenance, teardown of communication sessions; checkpointing.
    - **Protocols:** NetBIOS, RPC, SQL.
- **Layer 4 - Transport:** End-to-end communication, segmentation, and reliability.
    - **PDU:** Segment (TCP) / Datagram (UDP)
    - **Functions:** Flow control, error correction, sequencing, windowing.
    - **Protocols:** TCP, UDP.
- **Layer 3 - Network:** Routes packets using logical addressing.
    - **PDU:** Packet
    - **Functions:** Routing, path selection, logical addressing (IP), fragmentation.
    - **Devices:** Routers, Layer 3 Switches.
- **Layer 2 - Data Link:** Node-to-node data transfer; manages access to the physical medium.
    - **PDU:** Frame
    - **Sublayers:**
        - **Logical Link Control (LLC):** Error and flow control; identifies network layer protocols.
        - **Media Access Control (MAC):** Hardware addressing; manages medium access (CSMA/CD).
    - **Devices:** Switches, Bridges, NICs.
- **Layer 1 - Physical:** Transmits raw bits over physical media.
    - **PDU:** Bits
    - **Functions:** Electrical/optical signaling, physical topologies, bit synchronization.
    - **Devices:** Hubs, Repeaters, Cables, Transceivers.

## 1.2 Compare and contrast networking appliances, applications, and functions

### Appliances (Physical and Virtual)
- **Router:** Connects different networks; uses IP routing tables to select the best path (Layer 3).
- **Switch:** Connects devices within a LAN; uses MAC addresses to forward frames (Layer 2).
    - **Layer 3 Switch:** A switch with routing capabilities.
- **Firewall:** Blocks or allows traffic based on security rules. Can be stateful (Layer 4) or application-aware (NGFW - Layer 7).
- **IDS/IPS:**
    - **IDS (Detection):** Monitors and alerts on suspicious activity (out-of-band).
    - **IPS (Prevention):** Actively blocks malicious activity in real-time (in-line).
- **Load Balancer:** Distributes traffic across multiple servers to ensure availability and performance.
- **Proxy:** Acts as an intermediary between a client and a server; can provide caching and filtering.
- **NAS (Network-Attached Storage):** File-level centralized storage (uses CIFS/SMB/NFS).
- **SAN (Storage Area Network):** High-speed, block-level storage network (uses Fibre Channel/iSCSI).
- **Wireless:**
    - **Access Point (AP):** Bridges wireless clients to the wired network.
    - **Wireless Controller:** Centralized management for multiple "lightweight" APs.

### Applications
- **Content Delivery Network (CDN):** A geographically distributed network of proxy servers to provide high availability and performance by caching content closer to users.

### Functions
- **VPN (Virtual Private Network):** Creates an encrypted tunnel over a public network.
- **Quality of Service (QoS):** Prioritizes specific traffic types (like Voice or Video) to ensure performance.
- **Time to Live (TTL):** A value in an IP packet that prevents it from circulating indefinitely (decremented by each router).

## 1.3 Summarize cloud concepts and connectivity options

### Virtualization & Infrastructure
- **NFV (Network Functions Virtualization):** Running network services (firewalls, routers) as virtual machines on commodity hardware instead of dedicated physical appliances.
- **VPC (Virtual Private Cloud):** A private, isolated section of a public cloud provider's network.
- **Network Security Groups (NSG):** Instance-level virtual firewalls (stateful).
- **Network Security Lists:** Subnet-level firewall rules.

### Cloud Gateways
- **Internet Gateway:** Allows communication between instances in your VPC and the internet.
- **NAT Gateway:** Allows instances in a private subnet to connect to the internet (outbound only) while preventing the internet from initiating a connection with them.

### Connectivity Options
- **VPN:** Secure, encrypted connection over the public internet.
- **Direct Connect:** Dedicated, private physical link to a cloud provider (bypasses the internet; provides consistent performance).

### Cloud Models
- **Service Models:**
    - **SaaS:** Software via browser (e.g., Office 365, Gmail).
    - **PaaS:** Platform for developers to build/deploy apps (e.g., Heroku, Azure App Service).
    - **IaaS:** Virtualized hardware (servers, storage) (e.g., AWS EC2).
- **Deployment Models:** Public, Private, Hybrid, Community.

### Characteristics
- **Scalability:** Ability to increase capacity to handle growth.
- **Elasticity:** Ability to automatically scale resources up OR down based on demand.
- **Multitenancy:** Multiple customers sharing the same physical resources while remaining isolated.

## 1.4 Explain common networking ports, protocols, services, and traffic types

### Essential Ports and Protocols
| Protocol | Port | Description |
| :--- | :--- | :--- |
| **FTP** | 20/21 | File Transfer (20=Data, 21=Control). Insecure. |
| **SSH** | 22 | Secure Shell (Encrypted remote access). |
| **SFTP** | 22 | Secure FTP (FTP over SSH). |
| **Telnet** | 23 | Insecure remote access (Cleartext). |
| **SMTP** | 25 | Simple Mail Transfer (Sending email). |
| **DNS** | 53 | Domain Name System (Names to IPs). |
| **DHCP** | 67/68 | Dynamic Host Configuration (Auto IP). |
| **TFTP** | 69 | Trivial FTP (Simple, no auth, UDP). |
| **HTTP** | 80 | Web traffic (Unencrypted). |
| **NTP** | 123 | Network Time Protocol (Clock sync). |
| **SNMP** | 161/162 | Network Management (161=Queries, 162=Traps). |
| **LDAP** | 389 | Directory Access (Queries directory). |
| **HTTPS** | 443 | Secure Web (TLS/SSL). |
| **SMB** | 445 | Server Message Block (File/Print sharing). |
| **Syslog** | 514 | System Logging (UDP). |
| **SMTPS** | 587 | Secure SMTP (Submission). |
| **LDAPS** | 636 | Secure LDAP (over SSL/TLS). |
| **SQL Server** | 1433 | Microsoft SQL database traffic. |
| **RDP** | 3389 | Remote Desktop (GUI access). |
| **SIP** | 5060/5061 | VoIP Signaling (5060=TCP/UDP, 5061=TLS). |

### IP Types (Layer 4)
- **ICMP:** Used for diagnostics (Ping, Traceroute).
- **TCP:** Connection-oriented, reliable (Three-way handshake, sequencing, acknowledgments).
- **UDP:** Connectionless, fast (Best-effort, good for voice/video).
- **GRE:** Tunneling protocol that can encapsulate many protocols.
- **IPSec:** Security suite for IP traffic.
    - **AH (Authentication Header):** Integrity and authentication (No encryption).
    - **ESP (Encapsulating Security Payload):** Encryption, integrity, and authentication.
    - **IKE (Internet Key Exchange):** Manages keys for IPSec.

### Traffic Types
- **Unicast:** One-to-one communication.
- **Multicast:** One-to-many (to a specific group).
- **Anycast:** One-to-nearest (in a group of identical servers).
- **Broadcast:** One-to-all (on the local subnet).

## 1.5 Compare and contrast transmission media and transceivers

### Wireless
- **802.11 Standards:**
    - **802.11a:** 5 GHz, 54 Mbps.
    - **802.11b:** 2.4 GHz, 11 Mbps.
    - **802.11g:** 2.4 GHz, 54 Mbps.
    - **802.11n (Wi-Fi 4):** 2.4/5 GHz, 600 Mbps (MIMO).
    - **802.11ac (Wi-Fi 5):** 5 GHz, 3.5 Gbps (MU-MIMO).
    - **802.11ax (Wi-Fi 6):** 2.4/5/6 GHz, 9.6 Gbps (OFDMA, BSS Coloring).
- **Cellular:** Mobile data (LTE, 5G).
- **Satellite:** High-latency, wide coverage.

### Wired
- **Twisted Pair (802.3):**
    - **Cat 5e:** 1 Gbps (100m).
    - **Cat 6:** 1 Gbps (100m) or 10 Gbps (55m).
    - **Cat 6a:** 10 Gbps (100m).
- **Fiber:**
    - **Single-mode (SMF):** Long distance, laser light, thin core.
    - **Multimode (MMF):** Short distance, LED light, thicker core.
- **DAC (Direct Attach Copper):** Twinax copper with integrated SFP+ connectors (Short range, high speed).
- **Plenum:** Fire-resistant cable for air handling spaces (low smoke).

### Transceivers & Connectors
- **Form Factors:** SFP (1 Gbps), SFP+ (10 Gbps), QSFP (40 Gbps).
- **Fiber Connectors:**
    - **LC:** Small, push-pull (high density).
    - **SC:** Square, push-pull.
    - **ST:** Round, bayonet-style twist.
    - **MPO:** Multi-fiber (12 or 24 strands).
- **Copper Connectors:** RJ45 (Ethernet), RJ11 (Phone), F-type (Coax), BNC (Coax).
- **Polish Types:** UPC (Ultra Physical Contact - Blue), APC (Angled Physical Contact - Green, less reflection).

## 1.6 Compare and contrast network topologies, architectures, and types

### Topologies
- **Mesh:** Every node connects to every other node (Full) or some nodes (Partial). High redundancy.
- **Star:** All nodes connect to a central hub/switch.
- **Spine and Leaf:** Modern data center design; all leaf switches connect to all spine switches (predictable latency).
- **Bus:** All devices connect to a single backbone cable.
- **Ring:** Devices connected in a circle.

### Architecture
- **Three-Tier Hierarchical Model:**
    - **Core:** High-speed backbone (switching/routing).
    - **Distribution:** Aggregates access switches; applies policies/VLANs.
    - **Access:** Connects end-user devices (PoE common).
- **Collapsed Core:** Merges Core and Distribution into one layer.
- **Traffic Flows:**
    - **North-South:** In/out of the data center (Client to Server).
    - **East-West:** Between servers in the data center.

### Network Types
- **PAN:** Personal (Bluetooth).
- **LAN:** Local (Office/Home).
- **CAN:** Campus (Multiple buildings).
- **MAN:** Metropolitan (City-wide).
- **WAN:** Wide Area (Large distance/Internet).
- **SAN:** Storage Area (Block-level storage).

## 1.7 Given a scenario, use appropriate IPv4 network addressing

### Address Types
- **Public:** Globally routable.
- **Private (RFC 1918):**
    - `10.0.0.0 - 10.255.255.255`
    - `172.16.0.0 - 172.31.255.255`
    - `192.168.0.0 - 192.168.255.255`
- **APIPA:** `169.254.x.x` (Self-assigned when DHCP fails).
- **Loopback:** `127.0.0.1` (Testing the local stack).

### Classes
- **Class A:** 1-126 (/8)
- **Class B:** 128-191 (/16)
- **Class C:** 192-223 (/24)
- **Class D:** 224-239 (Multicast)
- **Class E:** 240-255 (Experimental)

### Subnetting
- **CIDR:** `/24` notation (e.g., 255.255.255.0).
- **VLSM:** Subnetting a subnet (different mask lengths for different sized subnets).

## 1.8 Summarize evolving use cases for modern network environments

### SDN & SD-WAN
- **SDN:** Decouples the **Control Plane** (decisions) from the **Data Plane** (forwarding).
- **SD-WAN:** Application-aware routing over multiple transport types (MPLS, Broadband, LTE).
    - **Zero-touch provisioning:** Devices auto-configure upon connection.

### Security Architectures
- **ZTA (Zero Trust Architecture):** "Never trust, always verify." Policy-based authentication and least privilege.
- **SASE/SSE:**
    - **SASE:** Convergence of WAN and Security (FWaaS, CASB, ZTNA) into a cloud service.
    - **SSE:** Security-focused subset of SASE.

### Infrastructure as Code (IaC)
- Managing infrastructure using definition files and source control.
- **Benefits:** Automation, consistency, version control.
- **Configuration Drift:** When an environment's state changes from the defined code.

### IPv6
- **Address Exhaustion:** IPv6 (128-bit) provides a virtually unlimited address space.
- **Coexistence:**
    - **Dual Stack:** Running both IPv4 and IPv6.
    - **Tunneling:** Carrying IPv6 over IPv4 networks.
    - **NAT64:** Allows IPv6-only clients to talk to IPv4-only servers.
