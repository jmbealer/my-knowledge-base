# 1.0 Networking Concepts (23%)

## 1.1 Explain concepts related to the Open Systems Interconnection (OSI) reference model

The OSI model is a conceptual framework developed by the **ISO in 1978** to standardize network communication into seven abstraction layers.

> **Mnemonic:** **A**ll **P**eople **S**eem **T**o **N**eed **D**ata **P**rocessing.

### The Seven Layers
- **Layer 7 - Application:** Interface for end-user processes and network services.
- **Layer 6 - Presentation:** Translates, encrypts, and compresses data.
- **Layer 5 - Session:** Manages sessions and dialogues between applications.
- **Layer 4 - Transport:** End-to-end communication, segmentation, and reliability.
- **Layer 3 - Network:** Routes packets using logical addressing.
- **Layer 2 - Data Link:** Node-to-node data transfer; hardware addressing.
- **Layer 1 - Physical:** Transmits raw bits over physical media.

## 1.2 Compare and contrast networking appliances, applications, and functions

### Appliances (Physical and Virtual)
- **Router:** Forwards data packets between networks (Layer 3).
- **Switch:** Connects devices within a segment (Layer 2).
- **Firewall:** Filters traffic based on security rules.
- **IDS/IPS:** Monitors (IDS) or blocks (IPS) malicious activity.
- **Load Balancer:** Distributes traffic across multiple servers.
- **Proxy:** Intermediary for client/server requests.
- **NAS (Network-Attached Storage):** File-level storage (SMB/NFS).
- **SAN (Storage Area Network):** Block-level storage network (FC/iSCSI).
- **Wireless AP & Controller:** AP bridges wireless; Controller manages APs.

### Applications
- **Content Delivery Network (CDN):** Distributed servers for fast content delivery.

### Functions
- **VPN (Virtual Private Network):** Encrypted tunnel.
- **Quality of Service (QoS):** Prioritizes specific traffic.
- **Time to Live (TTL):** Packet lifespan limit to prevent loops.

---

## 1.3 Summarize cloud concepts and connectivity options

### Cloud Infrastructure
- **NFV (Network Functions Virtualization):** Decoupling network services from hardware.
- **VPC (Virtual Private Cloud):** Isolated private cloud network.
- **Network Security Groups / Lists:** Cloud-based firewalls and ACLs.

### Connectivity & Gateways
- **Internet Gateway:** Connects VPC to the internet.
- **NAT Gateway:** Outbound-only internet for private instances.
- **Cloud VPN:** Encrypted tunnel over internet.
- **Direct Connect:** Dedicated physical link to cloud provider.

### Models & Characteristics
- **Service Models:** **SaaS** (Software), **PaaS** (Platform), **IaaS** (Infrastructure).
- **Deployment Models:** Public, Private, Hybrid.
- **Key Traits:** Scalability, Elasticity, Multitenancy, **Metered Utilization** (Pay-per-use).

### IP Types & IPSec
- **ICMP:** Diagnostics (Ping).
- **TCP / UDP:** Reliable vs. Fast transport.
- **GRE:** Generic tunneling.
- **IPSec:** **AH** (Integrity), **ESP** (Encryption), **IKE** (Key management).

### Traffic Types
- **Unicast:** One-to-one.
- **Multicast:** One-to-many.
- **Anycast:** One-to-nearest.
- **Broadcast:** One-to-all (IPv4 only).

## 1.5 Compare and contrast transmission media and transceivers

### Wired Media (802.3)
- **Cabling:** **Cat 5e/6/6a/7/8** (xBASE-y naming).
- **Fiber:** **Single-mode** (Long range) vs. **Multimode** (Short range).
- **Copper:** **Coaxial**, **Direct Attach Copper (DAC)**, **Twinaxial**.
- **Environmental:** **Plenum** (Fire-resistant) vs. Non-plenum.

### Transceivers & Connectors
- **Form Factors:** **SFP**, **QSFP**.
- **Protocols:** Ethernet, **Fibre Channel (FC)**.
- **Connectors:** **SC**, **LC**, **ST**, **MPO**, **RJ11**, **RJ45**, **F-type**, **BNC**.

---

## 1.6 Compare and contrast network topologies, architectures, and types

### Topologies
- **Mesh**, **Hybrid**, **Star (Hub & Spoke)**, **Spine and Leaf**, **Point-to-Point**.

### Architecture
- **Three-Tier:** **Core**, **Distribution**, **Access**.
- **Collapsed Core:** Merged core/distribution.
- **Traffic Flows:** **North-South** (In/Out), **East-West** (Between servers).

## 1.7 Given a scenario, use appropriate IPv4 network addressing

- **Address Types:** **Public**, **Private (RFC 1918)**, **APIPA**, **Loopback/Localhost**.
- **Subnetting:** **VLSM**, **CIDR**.
- **Classes:** Class A, B, C, D (Multicast), E (Experimental).

---

## 1.8 Summarize evolving use cases for modern network environments

- **SDN / SD-WAN:** Central policy, ZTP, Application aware, Transport agnostic.
- **VXLAN:** Layer 2 over Layer 3, **Data Center Interconnect (DCI)**.
- **Zero Trust (ZTA):** Policy-based auth, Authorization, **Least Privilege Access**.
- **SASE / SSE:** Converged WAN and security.
- **IaC:** Automation (**Playbooks/Templates**), **Source Control** (Version control, Branching), **Configuration Drift**.
- **IPv6:** Address exhaustion, **Tunneling**, **Dual Stack**, **NAT64**.
