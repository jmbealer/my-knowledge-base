# 4.0 Network Security (14%)

## 4.1 Explain the importance of basic network security concepts

### Logical & Physical Security
- **Logical Security (Software-based):**
    - **Encryption:**
        - **Data in Transit:** Protecting data moving over the wire (TLS, IPSec, SSH).
        - **Data at Rest:** Protecting stored data (Full Disk Encryption, Encrypted Databases).
    - **Certificates & PKI:**
        - **PKI (Public Key Infrastructure):** Using CAs (Certificate Authorities) to manage trust and keys.
        - **Self-signed:** Generated locally; no third-party trust, but useful for internal testing.
- **Physical Security:**
    - **Cameras & Locks:** Surveillance and controlled access to racks/rooms.
    - **Environmental Monitoring:** Sensors for heat, moisture, or unauthorized entry.

### Identity and Access Management (IAM)
- **Authentication (Who are you?):**
    - **MFA (Multi-Factor):** Something you know, have, are, or where you are.
    - **SSO (Single Sign-On):** One login for multiple systems (SAML/OAuth).
    - **RADIUS:** Standard for centralized network access (AAA).
    - **TACACS+:** Cisco-proprietary AAA; separates Authentication, Authorization, and Accounting; encrypts the entire packet.
- **Authorization (What can you do?):**
    - **Least Privilege:** Giving only the minimum access needed for the job.
    - **RBAC (Role-Based Access Control):** Permissions based on job function.

### Security Terminology
- **CIA Triad:**
    - **Confidentiality:** Preventing unauthorized disclosure.
    - **Integrity:** Preventing unauthorized modification.
    - **Availability:** Ensuring access when needed.
- **Honeypot / Honeynet:** Decoy systems/networks used to lure and study attackers.
- **Compliance:**
    - **PCI DSS:** Standards for credit card data.
    - **GDPR:** EU regulation for personal data privacy.

## 4.2 Summarize various types of attacks and their impact to the network

### Layer 2 & Network Attacks
- **MAC Flooding:** Filling the switch's MAC table with fake entries to force it to act like a hub (broadcasting everything).
- **ARP Poisoning / Spoofing:** Sending fake ARP replies to redirect traffic to the attacker (Man-in-the-Middle).
- **VLAN Hopping:** Bypassing VLAN isolation through double-tagging or switch spoofing.
- **DoS / DDoS:**
    - **DoS:** A single attacker overwhelming a target.
    - **DDoS:** Multiple attackers (Botnets) flooding a target.
- **Rogue Services:**
    - **Rogue DHCP:** An unauthorized DHCP server handing out wrong gateways/DNS.
    - **Rogue AP:** An unauthorized wireless access point connected to the wired network.
    - **Evil Twin:** A malicious AP masquerading as a legitimate one.

### DNS & Application Attacks
- **DNS Poisoning:** Corrupting a DNS cache to redirect users to fake websites.
- **On-path Attack (MitM):** Intercepting communication between two parties secretly.

### Social Engineering & Malware
- **Phishing:** Fraudulent messages to trick users.
- **Tailgating:** Following an authorized person into a secure area.
- **Malware:** Viruses, Worms, Trojans, Ransomware, and Spyware.

## 4.3 Given a scenario, apply network hardening techniques

### Device Hardening
- **Change Default Credentials:** The absolute first step for any new device.
- **Disable Unused Ports/Services:** Reduce the attack surface (e.g., disable Telnet, HTTP, unused switch ports).
- **Use Secure Protocols:** SSH instead of Telnet; HTTPS instead of HTTP; SNMP v3 instead of v2c.
- **Firmware Updates:** Regularly patching to fix known vulnerabilities.
- **Access Control Lists (ACLs):**
    - **Standard ACL:** Filters by Source IP only.
    - **Extended ACL:** Filters by Source/Destination IP, Port, and Protocol.

### Infrastructure Hardening
- **Port Security:** Limiting the number of MAC addresses allowed on a switch port; shutting down the port on violation.
- **Dynamic ARP Inspection (DAI):** Preventing ARP poisoning by validating ARP packets.
- **DHCP Snooping:** Preventing rogue DHCP servers by identifying "trusted" vs "untrusted" ports.

## 4.4 Given a scenario, implement and maintain a secure wireless network

### Wireless Hardening
- **Modern Encryption:** Use **WPA3** with SAE (Simultaneous Authentication of Equals). Use WPA2 (AES-CCMP) only if WPA3 isn't supported.
- **802.1X (WPA-Enterprise):** Using individual user credentials (RADIUS) instead of a shared password.
- **Management Frame Protection (MFP):** Preventing deauthentication attacks.

### Less Effective Measures (Security Through Obscurity)
- **Disable SSID Broadcast:** Hiding the network name (easy for attackers to find with scanners).
- **MAC Filtering:** Only allowing specific MAC addresses (easy for attackers to spoof).
- **Antenna Placement:** Limiting signal bleed outside the building.
- **Captive Portal:** Requiring a login or terms-of-service agreement before access.
