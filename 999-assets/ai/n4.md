# 4.0 Network Security (28%)

## 4.2 Summarize various types of attacks and their impact to the network

### Denial of Service (DoS)
- **SYN Flood:** Sending many TCP SYN packets but never completing the handshake to exhaust resources.
- **ICMP Flood (Smurf Attack):** Overwhelming a target with spoofed ICMP (ping) requests.

### DNS & On-Path Attacks
- **DNS Amplification:** Using small queries to trigger large DNS responses sent to the victim.
- **SSL Stripping:** Forcing a browser to use HTTP instead of HTTPS to capture credentials in cleartext.

### Malware Types
- **Rootkit:** Hides itself and other malware from the OS and security tools.
- **Logic Bomb:** Malicious code that stays dormant until a specific condition (date/event) is met.
