# 4.0 Network Security (28%)

## 4.2 Summarize various types of attacks and their impact to the network

### Network-Layer Attacks
- **VLAN Hopping:**
    - **Switch Spoofing:** Tricking a port into becoming a trunk using DTP.
    - **Double Tagging:** Nesting two 802.1Q tags to traverse VLANs.
- **MAC Flooding:** forces a switch to fail-open as a hub.

## 4.3 Given a scenario, apply network security features, defense techniques, and solutions

### Infrastructure Hardening
- **Port Security Violation Actions:**
    - **Shutdown:** Disables the port (standard).
    - **Restrict:** Drops traffic and increments counter/sends alert.
    - **Protect:** Drops traffic only (no alert).

### Firewall Architectures
- **Packet Filter:** Stateless; header-based.
- **Stateful:** Tracks session state.
- **Next-Gen (NGFW):** Deep Packet Inspection (DPI) and App-layer awareness.
