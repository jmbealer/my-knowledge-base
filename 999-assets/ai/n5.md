# 5.0 Network Troubleshooting (20%)

## 5.5 Given a scenario, use the appropriate tool to troubleshoot connectivity issues

### Basic Networking Device Commands (IOS-style)
- **show mac-address-table:** Displays the switch's MAC-to-port mappings.
- **show route:** Displays the IP routing table.
- **show interface:** Shows status, speed, duplex, and error counters for a port.
- **show config:** Displays the current running configuration.
- **show arp:** Displays the ARP cache (IP to MAC).
- **show vlan:** Shows VLAN assignments and status.
- **show power:** Displays PoE status and power budget usage.
