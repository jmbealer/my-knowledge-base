- ## 2.0 Network Implementation 20%

  - **Goal of Domain 2**:
    - This domain covers the actual deployment and configuration of networking devices and technologies including routing, switching, wireless, and physical installations.
    - It emphasizes practical implementation skills and is foundational for most real-world IT tasks.

  - **Things You Must Memorize**:
    - Differences between RIP, OSPF, BGP, EIGRP.
    - VLAN and trunk configurations (802.1Q).
    - 802.11 standards (speed, frequency, MIMO types).
    - Wireless security types (WPA2/WPA3, PSK/Enterprise).
    - Physical infrastructure components (MDF, IDF, Patch Panels).

- ### 2.1 Explain characteristics of routing technologies

  - **Static Routing**: *Manually configured* routing entries.
    - **Use Cases**: Small networks, stub networks, stable environments.
    - **Benefits**: Low overhead (no CPU/bandwidth used for updates), security (no protocol to exploit).
    - **Drawbacks**: No auto-failover, poor scalability.
  - **Dynamic Routing**: Routers *automatically exchange* path information using protocols.
    - **Use Cases**: Large networks, changing topologies.
    - **Benefits**: Scalability, adaptability, automatic failover.
  - **Routing Protocols**:
    - **RIP (Routing Information Protocol)**: *Distance-vector* using hop count (max 15).
    - **OSPF (Open Shortest Path First)**: *Link-state* using Dijkstra algorithm; organized into **Areas**.
    - **EIGRP (Enhanced Interior Gateway Routing Protocol)**: *Advanced distance-vector* using bandwidth and delay; fast convergence.
    - **BGP (Border Gateway Protocol)**: *Path-vector* protocol routing between **Autonomous Systems (AS)** on the internet.
  - **Route Selection Concepts**:
    - **Administrative Distance (AD)**: *Trustworthiness* of a route source (lower is better; e.g., Directly Connected = 0, Static = 1, OSPF = 110).
    - **Metric**: Value used to *evaluate the cost* of a path (e.g., Hop Count for RIP, Cost for OSPF).
    - **Prefix Length**: Number of bits identifying the network; **Longest Match Rule** applies first.
  - **Address Translation**:
    - **NAT (Network Address Translation)**: Mapping private IP space to public IP.
    - **PAT (Port Address Translation)**: Many-to-one mapping using unique source ports (Overloading).
  - **First Hop Redundancy Protocol (FHRP)**: Provides gateway redundancy (e.g., HSRP, VRRP).
    - **Virtual IP (VIP)**: Shared IP address used by the active gateway in a cluster.
  - **Subinterfaces**: *Logical interfaces* (e.g., eth0.10) on a physical port to support multiple VLANs (Router-on-a-Stick).

- ### 2.2 Given a scenario, configure switching technologies and features

  - **Virtual Local Area Network (VLAN)**: *Logical network segment* on a physical switch to isolate broadcast domains.
    - **VLAN ID**: Numerical identifier (1-4094).
    - **VLAN Database**: File (vlan.dat) storing VLAN info.
    - **SVI (Switch Virtual Interface)**: Layer 3 logical interface for inter-VLAN routing.
  - **Interface Configuration**:
    - **Access Port**: Carries traffic for a *single VLAN* (untagged).
    - **Trunk Port**: Carries traffic for *multiple VLANs* using **802.1Q** tagging.
    - **Native VLAN**: The one VLAN on a trunk that remains *untagged*.
    - **Voice VLAN**: Prioritizes VoIP traffic for better QoS.
  - **Spanning Tree Protocol (STP)**: Prevents Layer 2 loops by blocking redundant paths.
    - **RSTP (802.1w)**: Faster convergence version.
  - **Link Aggregation (LAG/EtherChannel)**: Combining physical ports into one logical link for throughput and redundancy.
    - **LACP (802.3ad)**: Standard protocol for dynamic negotiation.
  - **Port Settings**:
    - **Speed/Duplex**: Should be auto-negotiated; mismatch causes performance issues/drops.
    - **MTU (Maximum Transmission Unit)**: Standard is 1500 bytes.
    - **Jumbo Frames**: Frames > 1500 bytes (common in SANs) to reduce overhead.
  - **Power over Ethernet (PoE)**: Delivering power via Ethernet cable.
    - **802.3af (PoE)**: 15.4W
    - **802.3at (PoE+)**: 30W
    - **802.3bt (PoE++)**: 60-90W
  - **Switch Stacking**: Managing multiple physical switches as one logical unit.

- ### 2.3 Given a scenario, select and configure wireless devices and technologies

  - **802.11 Standards**:
    - **802.11n (Wi-Fi 4)**: 2.4/5 GHz, 600 Mbps, introduces **MIMO**.
    - **802.11ac (Wi-Fi 5)**: 5 GHz, 1.3 Gbps+, introduces **MU-MIMO**.
    - **802.11ax (Wi-Fi 6)**: 2.4/5/6 GHz, 10 Gbps, introduces **OFDMA**.
  - **Key Wireless Concepts**:
    - **MIMO (Multiple-Input Multiple-Output)**: Using multiple antennas to increase speed.
    - **MU-MIMO**: Simultaneous transmission to multiple clients.
    - **OFDMA**: Dividing channels into smaller resource units for efficiency.
  - **Frequencies & Channels**:
    - **2.4 GHz**: 11 channels (US); channels 1, 6, 11 are non-overlapping. High range, high interference.
    - **5 GHz**: Many more channels; less interference, higher speed, lower range.
    - **802.11h**: Adds **DFS** (Dynamic Frequency Selection) to avoid radar in 5 GHz.
    - **Band Steering**: Pushing dual-band clients to the 5 GHz band.
  - **SSID Identifiers**:
    - **SSID**: The network name.
    - **BSSID**: The MAC address of the AP radio.
    - **ESSID**: Network name across multiple APs.
  - **Wireless Modes**:
    - **Infrastructure**: Standard AP-based network.
    - **Ad Hoc (IBSS)**: Peer-to-peer.
    - **Mesh**: APs connect to each other wirelessly to extend coverage.
  - **Security & Authentication**:
    - **WPA2**: Uses **AES-CCMP** encryption.
    - **WPA3**: Uses **SAE** (Simultaneous Authentication of Equals).
    - **PSK (Pre-Shared Key)**: Simple passphrase for all.
    - **Enterprise (802.1X)**: Individual logins via **RADIUS**.
    - **Captive Portal**: Web page for guest authentication.
  - **Antennas**:
    - **Omnidirectional**: 360-degree coverage.
    - **Directional (Yagi/Patch)**: Focused signal for long distance.
  - **Management**:
    - **Autonomous AP**: Standalone management.
    - **Lightweight AP**: Managed by a **Wireless LAN Controller (WLC)** using **CAPWAP**.

- ### 2.4 Explain important factors of physical installations

  - **Infrastructure Locations**:
    - **MDF (Main Distribution Frame)**: Central point for the facility; connects to the ISP (Demarc).
    - **IDF (Intermediate Distribution Frame)**: Secondary racks connecting local users back to the MDF.
  - **Physical Layout**:
    - **Rack Units (U)**: 1.75 inches per U; standard width is 19 inches.
    - **Patch Panels**: Terminates horizontal cabling; allows easy reconfiguration with patch cords.
    - **Fiber Distribution Panel**: Specialized patch panel for fiber terminations.
  - **Power & Cooling**:
    - **UPS (Uninterruptible Power Supply)**: Battery backup for short outages.
    - **PDU (Power Distribution Unit)**: Power strip for rack equipment.
    - **Airflow**: Port-side exhaust/intake management (Hot aisle/Cold aisle).
  - **Environmental Factors**:
    - **Fire Suppression**: Clean agent systems (FM-200) for electronics.
    - **Humidity**: Keep between 40-60% to avoid static (low) or corrosion (high).
    - **Temperature**: Maintain consistent cooling to prevent thermal shutdown.
  - **Security**: Lockable racks and restricted room access (Mantrap, Bio-metrics).
